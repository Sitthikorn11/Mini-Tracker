# Tracker

Laravel backend and Vue frontend workspace.

## Structure

- `backend` - Laravel application
- `frontend` - Vue application powered by Vite
- `.tools` - portable PHP and Composer used by this workspace

## Common Commands

```powershell
.\php.cmd -v
.\composer.cmd --version
.\artisan.cmd --version
```

Run the Laravel backend:

```powershell
.\artisan.cmd serve
```

Run the Vue frontend:

```powershell
cd frontend
npm.cmd run dev
```
